# Categories

Per-category leaderboards are regenerated on every refresh by `scripts/render.mjs`.
Categories used in v1:

- `skill` — agent skills / capabilities
- `tool` — agent tools / commands
- `skin` — themes and visual variants
- `provider` — model / LLM provider bridges
- `ui-panel` — client-side UI panels
- `other` — anything else tagged `dsh-plugin`

Initial placeholder; each category file (`<category>.md`) will appear after the first refresh.
